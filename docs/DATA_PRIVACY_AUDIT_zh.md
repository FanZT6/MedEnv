# MedEnv 本地数据公开检查记录

检查日期：2026-11-09（Asia/Shanghai）。本记录仅报告文件种类、数量和检查结果，不包含真实病例内容或标识符。

## 结论

本地框架目录含有受限临床数据及其衍生产物，不能直接整体压缩或上传。当前检查未发现真实病例、临床图像或逐例轨迹被本地 Git 跟踪或保存在可达提交历史中；这不等于已核实远端仓库、既往发布附件或其他上传渠道。

公开范围是框架源码、MIMIC 处理过程及虚构测试样例。MIMIC 原始数据与患者级衍生产物保持私有，遵守适用的数据访问条件与使用协议。代码许可不能替代数据授权。

## 本地文件发现与删除影响

| 路径 | 检查发现 | 是否可公开 | 删除或迁移的影响 |
|---|---|---|---|

| `outputs/` | 81 个运行产物文件，2,994,542 字节；包含真实病例运行记录、逐例 JSON 轨迹、HTML 展示及本机配置路径 | 不随框架公开 | 不再需要运行记录时可以删除；后续评测自动创建新的输出目录，原有结果不会恢复 |

因此，`outputs/` 可以在确认不再需要结果后删除；`data/` 应按子目录处理，保留说明和合成样例。若不确定真实数据是否还有独立副本，先迁移到私有目录更合适。本次检查没有删除或移动上述文件。

## 检查范围与证据

- 枚举本地目录中的文件，包括被 Git 忽略的文件；`data/`、`outputs/` 未发现符号链接。
- 完整解析 `data/bench/` 的 10,810 个 JSON，零解析错误；检测到 `subject_id`、`hadm_id`、`stay_id`、`study_id`、`report_text` 等字段，以及 5,405 个 EHR 参考诊断与 5,405 个 OSCE 对象。这里只统计字段，不输出真实值。
- 输出目录中，61 个文件含可能的源数据标识符，45 个文件含本机绝对路径，7 个文件含临床字段名；这些统计按启发式匹配计数，同一文件可能重复出现在不同类别。
- 核实 `data/bench/`、`data/retrieval/` 与 `outputs/` 的全部 11,780 个文件均被 Git 忽略，无遗漏。
- 检查当前 Git 跟踪列表：未跟踪 `data/bench/`、`data/retrieval/` 或 `outputs/` 内的文件。跟踪列表中的部分旧合成 OSCE 和汇总统计文件已在工作区删除，尚未提交；其历史内容是虚构样例或总体统计。
- 检查本地 `git log --all` 的两个提交及 100 个唯一文件对象。历史数据对象是合成病例、测试图案和总体统计；未发现真实病例、影像或轨迹对象。
- 对排除私有数据、输出和缓存后的 98 个候选公开文件进行常见 API token、私钥、本机路径、私网地址和直接赋值的八位临床标识符启发式扫描；仅命中 `.gitignore` 的目录规则，该命中不是个人路径泄露。两个非文本文件为合成测试 PNG。预处理测试的病例与数据库在测试代码中以虚构内容构建。
- `python data_process/check_release.py` 通过：19 个文件，零错误。此脚本仅检查 `data_process/`，其通过不能代表整个目录可直接公开。
- `python scripts/validate_data.py --bench-root data/synthetic` 通过：四个子集各一个合成病例，零错误。

以上属于本地文件与 Git 检查，不能保证识别任意形式的秘密或所有临床文本，也没有验证远端当前内容、GitHub 附件、历史压缩包或第三方语料的逐项许可。本次文档和忽略规则变更不修改诊断逻辑，因此未重跑模型评测。
